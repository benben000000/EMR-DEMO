# Logos Directory

Place your hospital/clinic image assets in this folder with the following recommended names:

| File Name | Format | Recommended Dimensions | Usage |
|---|---|---|---|
| `logo-main.png` | PNG (Transparent) | 250 x 60 px | Main navbar header, login screen, official receipts |
| `logo-white.png` | PNG (Transparent) | 250 x 60 px | Dark sidebar / dark navbar background |
| `logo-phrm.png` | PNG (Transparent) | 200 x 50 px | Pharmacy dispensary receipts (optional) |
| `favicon.ico` | ICO / PNG | 32 x 32 px | Browser tab icon |
| `watermark.png` | PNG (Light/Faded) | 400 x 400 px | Background watermark for invoices and reports |

*Note: High-resolution PNGs with transparent backgrounds produce the best visual quality.*
