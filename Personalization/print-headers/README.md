# Print Headers Directory

Place pre-designed graphical header/banner images in this folder if the hospital uses graphical banners instead of plain text headers for printing:

| File Name | Format | Recommended Dimensions | Usage |
|---|---|---|---|
| `invoice-header.png` | PNG / JPG | 800 x 120 px | Billing receipt & invoice print top banner |
| `lab-header.png` | PNG / JPG | 800 x 120 px | Pathology & LIS lab report print top banner |
| `discharge-header.png` | PNG / JPG | 800 x 120 px | Inpatient discharge summary top banner |
| `prescription-header.png` | PNG / JPG | 800 x 120 px | Outpatient prescription slip top banner |
